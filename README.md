# Coffee Beans Recipes

A lightweight homepage prototype for a coffee bean library. It lets you:

- browse saved beans
- see the target flavor profile for each coffee
- click a bean to view its recommended recipe
- compare the last grind size and brew method
- automatically group coffees into clusters
- rate and sort beans by performance

## Run locally

Open `index.html` in a browser, or serve the folder with a simple static server:

```bash
python3 -m http.server 8000
```

Then visit:

- http://localhost:8000

## Files

- `index.html` — homepage structure
- `styles.css` — visual design and layout
- `script.js` — sample bean data and interactivity

## Notes

This is a strong starting point for your coffee workflow and can be expanded with:

- bean form to add custom roaster names and origins
- online lookup of coffee data by company and bean name
- saving actual brew logs and recipe history
- automatic recipe suggestions based on profile similarity
- sorting by roast freshness or roast date
